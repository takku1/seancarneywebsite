# apps/web

The SCE site: Astro 7, prerendered pages (`build.format: 'file'`) with a ClientRouter, deployed to Cloudflare Workers. The Worker serves only the APIs behind `src/middleware.ts`. Architecture details: [`docs/current/03-architecture.md`](../../docs/current/03-architecture.md).

## Layout

```text
src/
  pages/        routes; api/ holds the Worker endpoints (inquire, availability, scout, signal, csp-report)
  components/   by area: home, events, media, scout, layout, seo, analytics, ui
  layouts/      BaseLayout (head, router, persistent Scout/consent/player dock)
  lib/          logic by domain: inquiry, scout, media, analytics, integrations, seo, feeds
  data/         typed JSON content, validated at build (media-library.json is the media catalog)
  config/       site.ts: brand, contact and navigation constants
  assets/       prepared photos and covers (generated by the media tool; edit the catalog, not these)
  styles/       global tokens and base styles
public/         static files served as-is: icons, _headers, prepared media, downloads
integrations/   build-time Astro integrations: data validation, CSP header hashes
evals/          node:test unit tests (*.test.mjs) and the Scout eval harness
scripts/        Node entry points: media.mjs (wraps ../../scripts/media/media.py), prepare-brand.mjs
```

## Scripts

| Command | Does |
| :--- | :--- |
| `npm run dev` | Dev server on http://localhost:4321 |
| `npm run build` / `preview` | Production build to `dist/`, and a local preview of it |
| `npm run check` | Astro and TypeScript diagnostics |
| `npm test` | Unit tests in `evals/*.test.mjs` |
| `npm run test:browser` | After a build: every page at desktop and phone width, plus the API guards, against `astro preview` (installed Chrome) |
| `npm run eval:scout` | Scout concierge evaluation cases (against a running server, with an API key) |
| `npm run verify` | check, test, build and dependency audit: the full gate (CI runs the same, manually) |
| `npm run media:<list\|info\|build\|replace\|check\|report>` | Media catalog tool; see `docs/current/11-media-management.md` |
| `npm run brand:icons` | Regenerate favicon and install icons from the SCE wordmark |
| `npm run audit:deps` / `sbom` | Production dependency audit; CycloneDX SBOM to `docs/security/` |

## Configuration

`.env.example` documents every variable. Locally, copy it to `.env` (git-ignored); a blank key disables that integration and the site logs what it would send. In production, `PUBLIC_*` values are Cloudflare build variables and everything else is a Worker secret (`npx wrangler secret put NAME`). Setup walkthrough: [`docs/current/04-integrations-and-workflows.md`](../../docs/current/04-integrations-and-workflows.md).
